## 怎么用

本仓库只有 Markdown 文件，不需要安装依赖。想查看提交历史：

1. 打开 PowerShell 或终端
2. 切换到本仓库所在目录
3. 运行 `git log --oneline`

```powershell
PS C:\Users\lilli\Documents\tech-writing> git log --oneline
105116b (HEAD -> main, origin/main) docs: 添加环境盘点与排查记录
```
